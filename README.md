# TwinGuard

ต้นแบบเว็บแอปแจ้งเตือนมิจฉาชีพออนไลน์ ในกรอบหน้าจอ iPhone พร้อมหน้าจอภาษาไทย ใช้ HTML, CSS และ JavaScript ปกติ ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องมี API key และนำขึ้น GitHub Pages ได้โดยตรง

## ทดลองใช้งาน

- เลือก **สายโทรศัพท์**, **วิดีโอคอล** หรือ **ข้อความแชท**
- เลือกความเสี่ยง **ต่ำ / กลาง / สูง**
- แบนเนอร์แสดง AI กำลังวิเคราะห์ประมาณ 3.6 วินาที แล้วแสดงคะแนน 0–100
- กด **ดูรายละเอียด** เพื่อดูสัญญาณและบทสนทนาตัวอย่าง
- กด **เล่นการวิเคราะห์อีกครั้ง** เพื่อเริ่มใหม่
- ในหน้าแชท พิมพ์และส่งข้อความจำลองได้ ข้อความจะอยู่ในหน้านี้เท่านั้น

ระดับความเสี่ยง: ต่ำ 0–30, กลาง 31–69, สูง 70–100

## เปิดในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที โดยให้ไฟล์ทั้งหมดอยู่ในโฟลเดอร์เดียวกัน

หากมี Python และต้องการเปิดผ่าน local server:

```sh
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000` ขณะอยู่ในโฟลเดอร์นี้

## นำขึ้น GitHub Pages ผ่านหน้าเว็บ

1. แตกไฟล์ ZIP ก่อน ไม่ต้องอัปโหลด ZIP ทั้งก้อน
2. สร้าง repository ใน GitHub เช่น `twinguard-prototype` หากใช้ GitHub Free ให้เลือก Public เพื่อใช้ Pages
3. อัปโหลด **ไฟล์ภายในโฟลเดอร์ TwinGuard** ไว้ที่ระดับบนสุดของ repository: `index.html`, `style.css`, `app.js`, `portrait.png`, `README.md` และ `.nojekyll` อย่าอัปโหลดเป็นโฟลเดอร์ซ้อนอีกชั้น
4. บันทึกไฟล์ลง branch `main`
5. เปิด **Settings → Pages**
6. ใน **Build and deployment → Source** เลือก **Deploy from a branch**
7. เลือก branch **main** และโฟลเดอร์ **/(root)** แล้วกด **Save**
8. รอให้เผยแพร่สำเร็จ แล้วเปิดลิงก์ที่ GitHub แสดงบนหน้า Pages โดยทั่วไปจะเป็น `https://YOUR-USERNAME.github.io/twinguard-prototype/`

ไม่ต้องตั้ง Build command, ไม่ต้องใช้ npm และไม่ต้องสร้าง GitHub Actions workflow เพิ่ม

คู่มือทางการ: https://docs.github.com/en/pages/quickstart

## โครงสร้างและจุดแก้ไข

```text
TwinGuard/
├── index.html   # โครงหน้า ชื่อแอป และแผงเลือกสถานการณ์
├── style.css    # สี เลย์เอาต์ กรอบ iPhone และ responsive
├── app.js       # สถานการณ์ คะแนน แบนเนอร์ และการโต้ตอบ
├── portrait.png # ภาพบุคคลสมมติที่สร้างด้วย AI สำหรับวิดีโอคอล
├── .nojekyll    # ใช้ไฟล์เว็บโดยตรงบน GitHub Pages
└── README.md
```

- เปลี่ยนข้อความตัวอย่าง/คะแนน: ตัวแปร `data` ใน `app.js` แยกตาม `call`, `video`, `chat` และ `low`, `medium`, `high`
- เปลี่ยนเวลาวิเคราะห์: ค่า `3600` ใน `startAnalysis()` หน่วยมิลลิวินาที
- เปลี่ยนข้อความแบรนด์: `index.html` และ `renderResult()` ใน `app.js`
- เปลี่ยนรูปวิดีโอคอล: แทนที่ `portrait.png` ด้วยรูปใหม่ชื่อเดิม
- ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts หากไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ระบบแทน

## ขอบเขตของ Prototype

คะแนนและการตรวจจับเป็นข้อมูลสาธิตที่กำหนดไว้ล่วงหน้า การส่งข้อความไม่ได้ทำให้ AI วิเคราะห์ข้อความจริง แต่เล่นผลตามระดับความเสี่ยงที่เลือกใหม่อีกครั้ง ภาพวิดีโอคอลเป็นภาพนิ่งของบุคคลสมมติ

แอปไม่เข้าถึงไมโครโฟน กล้อง สายโทรศัพท์ ข้อความจริง หรือธุรกรรม ไม่มีการตัดสายอัตโนมัติและไม่มีการบล็อกธุรกรรม ปุ่มวางสายเป็นการจบฉากจำลองตามการเลือกของผู้ใช้

ยังไม่ได้อัปโหลดชุดโค้ดนี้ไปยังบัญชี GitHub ของคุณ ให้ทำตามขั้นตอนด้านบนเพื่อเผยแพร่
